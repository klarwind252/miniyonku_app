⚙ 機材設定

各機材の設定（ch。GWはWiFi・サーバーも）を変更し、USBで1台ずつ書き込みます（PC・Chrome/Edge限定）。

❓ 使い方（クリックで開閉）

🔰 初回だけ（最初の1回）

これが済むまでは、書き込んでも反映されません。

  1. サーバーに pip install esp-idf-nvs-partition-gen → 再起動。
  2. 各機材に「NVS対応版ファーム」を一度だけ pio run -e <env> -t upload で焼く。
  3. この画面を Ctrl+F5 で開き直す。

詳しくは資料「30_初回セットアップ」。

🔁 いつもの操作（設定を変える）

  1. 対象機材を選ぶ（GWはWiFi欄も出る／SE・RC・SGはch だけ）。
  2. 値を入力（空欄の項目は「今のまま」）。
    必要なら「💾保存」で記憶。
  3. 機材をUSB接続（1台・バッテリー外す）→「🔌接続してMAC確認」。
  4. 表示された機材名が選んだ機材と合っていたら「⬇設定を書き込む」。ログに [CFG] src=NVS が出れば成功。

💾保存＝アプリに覚えさせるだけ／⬇書き込む＝機材に反映。両方必要。
プログラム自体を入れ替えるとき（②ファーム本体）は資料「31_更新」を参照。

⚠ 書き込み前に必ず確認
  • 接続するGWは1台だけにしてください（複数同時接続は不可）。
  • モバイルバッテリーを外してからUSBを接続（USB給電と競合します）。
  • 書き込み中はUSBを抜かない／電源を切らない。
  • 対応ブラウザは Chrome / Edge のみ（Web Serial）。
  • chは全機材で同一が絶対条件（GWの接続先APのchとも一致）。chを変えるときは GW＋全ノードを同じ値で焼き直し、APも同じchに合わせてください（1台でもズレると計測が全滅します）。

🛠 ファーム登録（開発用）

  

    開発PCでビルド→マージした factory.bin を機材(env)ごとに登録します。書き込みPCはここから取得して焼くだけ。
  

  

    

      
    

    

      

  

  

    

  

    
  

  

  

    factory.bin の作り方
    
ESP32 (gw/gw7/sq0..5):
esptool --chip esp32 merge_bin -o factory.bin \
  0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin

ESP32-C3 (rc8/rc9/sg10/sg11):
esptool --chip esp32c3 merge_bin -o factory.bin \
  0x0 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin

各ファイルは .pio/build/<env>/ にあります。
