# ファーム反映分 2026-10-31（全機種）
common/espnow_link.h を変更したため **GW・SE全台・RC** を再ビルド＆焼き直し（プロトコル互換＝混在運用可）。

| ファイル | 内容 |
|---|---|
| common/espnow_link.h | A4 boot_id をRF起動後に採番／A6 esp_now_send 失敗をログ（1秒1行）／A7 重複排除リングをクリティカルセクション保護 |
| gate/src/main.cpp | A1 EVENT_ACK を全試行のseqで照合（ACK擦れ違いによる不要再送・偽LOSTを解消） |
| gw/src/main.cpp (rev4) | rev3（HTTPS接続使い回し・用途別タイムアウト・netタスク・受信キュー・RAM件数）＋ A1 同一通過(src,boot,lane,t_us)の重複記録を間引き |
| remote/src/main.cpp | 常時起動版：ACK待ち＋時間差再送（ノンブロッキング）／GW計測中はch走査しない／Serial非ブロッキング |

焼き順：GW → SE → RC。
  cd firmware/gw     && pio run -e gw6a -t upload
  cd firmware/gate   && pio run -e sq0 -t upload  （sq1…sq5 同様）
  cd firmware/remote && pio run -e rc8 -t upload --upload-port COMx
確認：GWシリアルに `[EV] dup …` が出れば再送重複を吸収している。`[MESH] esp_now_send err` が頻出なら要相談。
